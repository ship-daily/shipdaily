# Security Policy

## Reporting a vulnerability

Please **don't** open a public issue, discussion or Discord message about a security problem.

Report it privately through GitHub instead: [**Report a vulnerability**](https://github.com/ship-daily/shipdaily/security/advisories/new).

Include what you found, how to reproduce it, and the impact you expect. We'll acknowledge your report within 3 days and keep you updated until it's fixed. Once a fix is released, we're happy to credit you in the advisory unless you'd rather stay anonymous.

## Scope

In scope:

- The code in this repository
- The hosted app at [shipdaily.ai](https://shipdaily.ai)

Out of scope:

- Denial-of-service and volume-based attacks
- Social engineering of maintainers or users
- Issues in third-party services we depend on (report those to the vendor)

## Ranking and anti-abuse rules

Some anti-abuse thresholds and ranking weights are intentionally kept out of this repository. Finding ways to game launches, votes or credits is in scope: please report them privately too, so they can be fixed before they're exploited.

## Supported versions

Only the latest version on `main` (what runs on shipdaily.ai) receives security fixes.
